AUNELYA WEB ASSETS
===================

Formato entregado: WEBP optimizado para web.
Los dos archivos cutout mantienen transparencia.

Estructura:
- hero/: asset principal del hero
- products/: producto aislado, color blanco y rosa, y kit incluido
- sections/: imágenes de secciones
- sections/cards/: tarjetas pequeñas

Sugerencia de uso:
- hero-desktop.webp -> hero principal desktop
- product-*-cutout.webp -> secciones de producto / variantes
- whats-included.webp -> bloque Qué incluye
- bienestar-rutina-main.webp -> bloque grande Bienestar en tu rutina
- cards/*.webp -> tarjetas pequeñas de uso
- tecnologia-product-beauty.webp -> bloque de tecnología / características

Manifest incluido en manifest.json.
